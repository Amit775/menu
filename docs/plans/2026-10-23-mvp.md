## Decisions taken while implementing

- Cross-domain needs inside the API go through ports in `scope:shared` libs wired by `apps/api` (ADR 0004). The request's principal (account id, Admin flag, owned venue ids) is resolved once by the auth guard, so `menus` checks `canEditMenu` without importing `users`.
- `discover` is a read model: its repository reads the `menus` and `entries` tables read-only and never returns an entry's author.
- Scores are computed on read for the MVP (friends-scale data); an `ItemScore` table can replace it behind the same `RankingStrategy`.
